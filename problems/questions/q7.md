Q3:
First and Last Occurrence
Problem Statement
Given an array and a target value X, find the first and last position where X occurs.
Positions are 0-based.
If the target does not occur, print -1 -1.
Input Format
N X
A1 A2 ... AN
Output Format
first_position last_position
Constraints
1 ≤ N ≤ 1000
-10^5 ≤ Ai, X ≤ 10^5
Sample Test Cases
TC	 Input	          Output
1	 6 5
      2 5 3 5 7 5	     1 5
2	 5 10
      10 20 30 40 50     0 0
3	 5 10
      20 30 40 50 60    -1 -1
